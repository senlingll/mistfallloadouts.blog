What is already live from the Season 1 roadmap?

The August roadmap graphic groups new activities into Season 1 phases, but the later Steam notices are better evidence for availability. Soul Harvest arrived with the August 12 update. Its announcement describes a new gameplay mode connected to a new stage of the Fate Chart. That is a dated release, so it is no longer just an upcoming roadmap item. The September 15 update then changed several Season Task requirements and removed the rule that could reset all task progress unless every objective was completed in one session. Those changes matter if you are checking whether a planned seasonal task system has actually reached the live game.

Brandrgarde Solo Mode is also live. The September 3 announcement says it opened for both Normal and Cataclysm difficulties after that update. The roadmap image had presented solo play as planned work; the dated notice now settles its status. The Golden Woodling event is the newest roadmap-linked activity: the September 23 maintenance announcement says it starts at 02:00 UTC on September 24 and lasts until Season 1 ends. That is one day later than the notice's publication date. If a page or social post says September 23 is the event start, check whether it is confusing the maintenance date with the stated event time.

For a run today, use the event panel and current client as the final availability check. A roadmap image can remain online after one of its entries has shipped, while a limited event can stop when its published window closes. These are different states: an item can be delivered, an event can be active for a defined season window, and a future phase can still have no date. Keeping those labels separate is more useful than calling every item simply 'coming soon.'

Which Mistfall Hunter roadmap items still have no date?

Season 2 is even less specific. The graphic teases a new weapon, a season-exclusive theme and gameplay, and a progression system. It does not state a Season 2 launch date or a date for any individual feature. The safest summary is therefore simple: named roadmap content is not automatically scheduled content. A published date should come from a newer official notice. Until then, describe the entry as announced and undated, and avoid turning community speculation, reposted graphics, or search snippets into a promise from the developer.

What did the latest Mistfall Hunter update say about performance?

DevNote #9 was published on September 24, after the September 23 maintenance notice. The developer says the note addresses core gameplay experience and client-server performance feedback. Its opening discusses hit registration being finalized on the game server and the related damage-prediction errors players may notice when network latency separates an impact effect from the server result. The note says it will cover completed optimizations as well as future plans.

That makes DevNote #9 relevant to players tracking the health of the live game, but it should not be confused with a new content phase. The announcement does not give a date for the Ancestor Tree event, Season 2, or the roadmap's other undated entries. It also does not promise a universal performance result for every PC or connection. Read it as a developer explanation of current technical work, then use the later dated patch notes to confirm when a specific change reaches the client.

If you are comparing reports, note the difference between a developer plan and a shipped patch. A plan describes intended work; a live-update notice identifies changes players can install. For a practical run setup, keep the game updated and use the site's current gameplay guide for extraction decisions rather than relying on a performance guarantee that the announcement does not make.

How to check the next roadmap update without guessing

Use the Steam announcement date and the announcement's wording together. A headline such as maintenance update may include an event start time, but the maintenance date is not necessarily the event date. Check the timezone too: the September 23 notice explicitly gives 02:00 UTC on September 24 for Golden Woodling. If your local calendar shows a different date, convert from UTC and label that as a local-time conversion rather than changing the source date.

For roadmap entries with no date, recheck the official announcement feed and the game client close to the time you plan to play. A new date may be posted after this page's checked date. If two fan guides disagree, prefer the first-party notice and distinguish a confirmed live feature from a preview.
