Builds

Modèles de build qui évitent les erreurs de lancement

Les premiers builds échouent souvent quand ils empilent les dégâts sans prévoir l'évasion, les rôles ou les ressources.

Extracteur sûr

Idéal pour: Solo, début, joueurs prudents

Priorités: Mobilité, sustain, outils d'évasion

À éviter: Sacrifier l'évasion pour les dégâts

Raider équilibré

Idéal pour: Groupes mixtes

Priorités: Arme fiable, couche défensive, utilité flexible

À éviter: Dupliquer le même rôle

Briseur de boss

Idéal pour: Pression planifiée sur boss

Priorités: Burst, uptime, option de récupération

À éviter: Entrer sans route de récupération

Appel d'éclaireur

Idéal pour: Équipes qui ont besoin d'information

Priorités: Vision, mobilité, désengagement discret

À éviter: Combattre chaque contact
